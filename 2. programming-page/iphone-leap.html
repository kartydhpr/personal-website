How it works

How Leap works.

What gets compared, and how the lists are built.

Leap runs in your browser. It looks up two iPhones in a local dataset, then lists hardware the newer one has that yours does not, and anything you would lose by switching.

  1. Each model is a record.

    The dataset covers iPhone 8 through iPhone 18 Pro, 18 Pro Max, and iPhone Duo. A phone is stored as chip generation, last supported iOS, cameras, radios, Face ID or Touch ID, whether it folds, and other hardware flags.

  2. A feature is a yes-or-no check.

    Camera Control, Memory Integrity Enforcement, Smart Take, and the rest each have a requirement. Leap shows a feature when the phone you are considering meets it and the phone you have does not.

  3. Software and hardware stay separate.

    If your iPhone stopped getting iOS updates, Leap also lists system features that need a later version, such as Liquid Glass, RCS, and StandBy. If you already run the latest iOS, those stay off the list, because a software update can add them.

  4. The highlight row is a short subset.

    “What you’d actually notice” is up to six of the highest-weight unlocks, with at most two from the same category, and nothing below a usefulness floor. The full list underneath is every unlock, grouped by camera, display, intelligence, and the rest.

  5. Losses use the same checks in reverse.

    Moving to iPhone Duo can mean giving up Face ID, a telephoto, or LiDAR. Leap runs the feature list the other way and shows what your current phone has that the target does not.

  6. The pair is stored in the URL.

    Choosing two phones writes #from=iphone-13&to=iphone-18-pro without reloading. Open that link to see the same comparison. In-page links scroll in place so they do not reset the pair.

No account and no server. The dataset and compare logic ship as two scripts on this page. Specs and gates were compiled from public reporting as of September 2026. Unofficial, and not affiliated with Apple.
